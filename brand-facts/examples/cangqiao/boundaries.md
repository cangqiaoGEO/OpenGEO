# 三不承诺（口径宪章）

不承诺排名第一；不承诺被所有 AI 推荐；不承诺统一的见效天数。只承诺：诊断分数、改进清单、复测对比。

# 不适用 / 不接

- 批量低质软文、AI 投毒类需求不接；
- 期望「几小时见效」「保排名」的客户不适合我们；
- 无真实产品与交付能力、仅想做信息差生意的合作不参与。
