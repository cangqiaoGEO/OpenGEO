# S6 官网地基 Skill

**铁律（每个 Skill 提示词首行）**：所有输出只准引用《品牌事实库》，库里没有的事实不得编造；只可引用 `status: stable` 且未过 `stale_after` 的概念；产出末尾列出所引用的概念文件清单；产出前按「AI 友好七特征」自查并报告达标数（≥5 才交付）。

## 职责
检查并修复「让 AI 看见你」的技术地基。

## 创建指令
> 创建一个「GEO官网地基」技能。触发词：「查官网地基」。动作：对目标官网按 7 条清单逐项检查——①可正常访问（含备案）②内容可被抓取（不整页图片）③关键信息不锁登录④sitemap/robots 基础配置⑤品牌名全网统一（与事实库 identity.md 一致）⑥有 FAQ 页⑦有清晰联系入口。输出：整改清单（按 P0/P1 排序）+ 基于事实库生成的 FAQ 页面稿。

## 输入 → 输出
官网 URL + 事实库 → 地基体检表 + 整改清单 + FAQ 页面稿
