# OpenGEO 原有材料路由

不要复制材料形成第二份事实源。运行时从 WorkBuddy 项目目录读取下列现有文件，并在 `00-geo-material-map.md` 中记录实际使用路径。

## 1. 唯一事实源

根目录：`brand-facts/examples/cangqiao/`

- `identity.md`：公司主体与名称；
- `audience.md`：受众与三层决策问题；
- `intent-words.md`：攻略、对比、口碑三层意图词；
- `boundaries.md`：不承诺排名、全平台推荐或固定见效时间等红线；
- `channels.md`：官网、OpenGEO 仓库、线下与微信入口；
- `products/geo-course.md`、`products/geo-operations.md`：课程与代运营能力、交付物和边界；
- `evidence/`：只引用状态合格、可追溯的证据；
- `faq.md`：GEO 定义、差异、诊断、见效和开始方式；
- `diagnosis/2026-08-21-baseline.md`：公开自测的稳定基线；
- `monitors/weekly.md`：复测问题集与过程内容来源。

`positioning.md` 只有在文件状态已经变为 `stable` 后才可用于正式定位。

## 4. 选题合成规则

每个候选选题必须同时具备：

1. 与用户原始主题直接相关，不替换或扩张成其他业务主题；
2. 一个稳定意图词；
3. 一个 GEO 四步阶段：看见、看懂、相信、推荐；
4. 至少一个稳定事实或可验证证据；
5. 一个有效且未过期的 CTA。

优先内容柱：

- **公开自测**：18 分基线、做了什么、下一次如何复测；
- **方法科普**：四步法、六维诊断、三层意图、一库一脑七技一环；
- **避坑对比**：不承诺排名、白帽边界、课程交付验收；
- **开源过程**：打开 OpenGEO 仓库、事实库、诊断报告和工具脚本进行真人演示。

## 5. AI 友好七特征的视频化自查

1. 结构化：大字标题 → 3 秒钩子 → 核心答案 → 大字卡清单 → CTA；
2. 深度化：只讲透一个问题，不做空泛口号；
3. 可调用：使用 `channels.md` 中有效入口；
4. 全网统一：公司全称、OpenGEO、卖点与边界一致；
5. 证据链：口播与大字卡使用可追溯报告、仓库、记录；
6. 反向匹配：明确命中一个三层意图词；
7. FAQ：标题/口播直接回答一个真实问题。

至少 5/7 达标才能交付脚本；未达标时给出补强项。
