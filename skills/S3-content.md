# S3 内容 Skill

**铁律（每个 Skill 提示词首行）**：所有输出只准引用《品牌事实库》，库里没有的事实不得编造；只可引用 `status: stable` 且未过 `stale_after` 的概念；产出末尾列出所引用的概念文件清单；产出前按「AI 友好七特征」自查并报告达标数（≥5 才交付）。

## 职责
按八段式结构生产 GEO 文章，唯一信息源是品牌事实库。

## 创建指令
> 创建一个「GEO八段式写作」技能。触发词：「写一篇[意图词]」。动作：读取品牌事实库全部 stable 概念与意图词清单，产出八段式文章：标题（含核心标签）→ 40~80 字核心答案 → 为什么重要 → 原理/方法 → 方案对比（含表格）→ 真实案例+数据（只用事实库 evidence/）→ 下一步行动（channels.md 的入口）→ FAQ（5~10 问，取自 faq.md）。质量红线：≥800 字、≥3 个证据点。产出存入 `内容库/待审/`，等待人工审核，禁止直接发布。

## 输入 → 输出
事实库 + 1 个意图词 → 1 篇待审八段式文章（含引用概念清单与七特征自查报告）
