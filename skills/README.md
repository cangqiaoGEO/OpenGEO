# 七技（Skills）

| Skill | 职责 | 形态 |
| --- | --- | --- |
| [S1 诊断](S1-diagnosis/) | 多通道证据诊断；样本充分时输出实验性六维评分与建议 | 完整工程（Schema、采集、审计、报告、测试、WorkBuddy 打包） |
| [S2 意图词](geo-intent-words/) | 三层意图各 20~30 个问题 + 覆盖审计 | 完整可运行技能（WorkBuddy 可导入） |
| [S3 内容](S3-content/) | 八段式待审文章（≥800字、≥3证据点） | 完整技能（事实门禁、标准与模板） |
| [S4 短视频](S4-short-video/) | 白帽口播脚本 + AI 可识别大字标题 | 完整技能（结构、拍摄与私信边界） |
| [S5 信源发布](S5-publishing/) | 已审内容多平台发布包 + 可选 PDF | 完整技能（人工发布门禁与 PDF 脚本） |
| [S6 官网地基](S6-website-foundation/) | 7 条地基体检 + 单文件官网/FAQ | 完整技能（设计资源、HTML 模板与校验器） |
| [S7 复测监测](geo-weekly-monitor/) | 20问周测+趋势+验证回写 | 完整可运行技能（WorkBuddy 可导入） |
| [总控](orchestrator.md) | 拆任务、验产出、出周报 | 团长提示词 |
| [自动化](automation/) | 日更 + 周测两条定时任务 | 配置模板 |

S2–S6 的品牌主张共享同一条铁律：**只准引用品牌事实库，只引用 stable 且未过期的概念，产出必须列引用清单。** S1/S7 可以记录外部平台观测，但观测不是品牌事实，不得自动回写或提升事实状态。

S1 同步自 `cangqiaoedu-skills/brand-geo-audit` 的 v0.6.0 实现；S3/S4/S6 吸收对应源技能的模板与参考资源，S5 吸收 `markdown-to-pdf`，并统一适配 OpenGEO 的事实库、白帽、人工审核和不承诺口径。
