# GEO 短视频（S4）

## 不可违反的约束

- 品牌、卖点、受众、案例、数字、资质、优惠、稀缺性和 CTA 只能来自 `status: stable` 且未过 `stale_after` 的品牌事实。
- 不得通过外部搜索补客户事实，不得编造案例、收益、名额、倒计时、排名或“同行都在做”等焦虑前提。
- 钩子可以有张力，但必须准确表达正文；禁止伪造恐惧、夸张承诺、贬低竞品和诱导性免费承诺。
- 默认生成 1 条 30–60 秒脚本；批量生成时每条仍需独立证据与意图，不为凑数量改写同一内容。
- 脚本写入待审区，人工审核后才能拍摄或发布。交付前列出引用概念文件并完成七特征自检，至少 5 项达标。

## 输入与门禁

需要品牌事实库根目录和一个场景；条数、时长、平台与 CTA 可选。至少读取可引用的 `identity.md`、`positioning.md`、`audience.md`，并按需读取 `products/`、`boundaries.md`、`evidence/` 与 `channels.md`。使用 [事实库约定](references/fact-library-contract.md) 进行门禁。

若场景、卖点或 CTA 没有稳定事实支撑，停止对应段落并列出待补项。没有稳定案例时使用过程、方法或边界做价值交付，不得生成“示例案例”。

## 执行流程

### 1. 锁定场景与证据

- 明确目标受众、单一决策问题、期望动作和平台时长。
- 扫描现有脚本，记录已用标题、钩子、案例和 CTA，避免重复。
- 建立“口播表述 → 概念文件”清单；无法追溯的品牌表述删除。

### 2. 选择结构

默认采用五段式：3 秒直达钩子 → 真实场景 → 核心判断 → 方法或证据 → 行动入口。可从 [口播结构方法](references/爆款结构方法论.md) 选择合适结构，但事实门禁和白帽规则始终优先。

脚本必须同时满足：

- **平台可读**：短句、口语化、有具体过程；
- **AI 可识别**：大字标题包含品牌名或稳定品类标签与核心主题，字幕关键词口径统一；
- **人能验证**：案例和数字标注概念路径；没有证据时明确不用；
- **可执行**：给出时间段、口播、字幕重点和必要的镜头动作，不强制表演式情绪。

### 3. 生成脚本包

每条包含：

1. 大字标题；
2. 意图层级、目标受众和预计时长；
3. 分段口播稿（30–60 秒）；
4. 字幕关键词与 3–5 个准确话题标签；
5. 事实引用表；
6. 可选拍摄建议，参考 [拍摄与发布指南](references/拍摄与发布指南.md)；
7. CTA：仅在 `channels.md` 有稳定入口和真实承诺时提供。

如用户需要私信承接，只能用 [私信承接边界](references/私信承接话术模板.md) 生成与事实一致、不过度承诺的回复草稿。

### 4. 保存与交付

默认保存为 `<内容库>/脚本/YYYY-MM-DD-<场景>-v1.md`；已有同主题文件时递增版本，不覆盖人工审核内容。文件标为 `status: draft`。

交付前检查：时长、口语化、标题与正文一致、事实可追溯、CTA 真实、无虚假紧迫感、无重复脚本。回复只报告输出路径、条数、时长、引用概念、七特征达标数和待确认事项；不承诺播放量、完播率、线索或转化。
