# 私信承接边界与模板

私信回复是待审草稿，不授权自动发送、批量触达或收集超出服务所需的个人信息。

## 约束

- 只承诺事实库明确记录且团队能够履行的服务。
- “免费”“限时”“名额”“几分钟出结果”等表述必须有稳定事实与真实履约能力；否则删除。
- 不把自动评分写成专业鉴定，不承诺排名、客户损失、收入提升或见效时间。
- 只询问完成当前服务所需的最少信息，并说明用途；不要索取密码、验证码或敏感身份信息。
- 需要诊断时转交 S1，保留实际平台、问题、时间与证据；不得先写结论再补数据。

## 首次回复

```text
收到你的“<关键词>”咨询。为了判断这项服务是否适用，请提供：<最少必要信息>。这些信息只用于<用途>；如果不方便公开，可以改用<安全渠道>。
```

## 说明下一步

```text
我们会按<事实库中的真实流程>处理，并在<真实可履行的时间口径>反馈<明确交付物>。结果只基于实际取得的材料和观测；证据不足的部分会标为未验证。
```

## 转人工

遇到价格承诺、合同、投诉、隐私、账号权限或无法核验的效果问题时，停止自动回复并转交负责人。不要用模板替负责人作出承诺。
