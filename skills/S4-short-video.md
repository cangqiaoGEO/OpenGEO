# S4 短视频 Skill

**铁律（每个 Skill 提示词首行）**：所有输出只准引用《品牌事实库》，库里没有的事实不得编造；只可引用 `status: stable` 且未过 `stale_after` 的概念；产出末尾列出所引用的概念文件清单；产出前按「AI 友好七特征」自查并报告达标数（≥5 才交付）。

## 职责
产出「算法+AI 双满足」的短视频口播脚本：过程化内容拿平台流量，大字标题喂 AI 关键词。

## 创建指令
> 创建一个「GEO短视频脚本」技能。触发词：「出[场景]口播脚本」。动作：读取品牌事实库的卖点与场景，产出：①大字标题（含品牌名+核心卖点关键词，AI 抓取时知道你是谁、卖什么）②30~60 秒口播稿（3 秒真实过程钩子，不吹不擂，让过程本身成为说服力）③话题标签方案（统一打核心标签）。实拍素材优先，禁止 AI 生成真人出镜画面。产出存 `内容库/脚本/`。

## 输入 → 输出
事实库 + 场景 → 脚本（大字标题 + 口播稿 + 标签方案）
