## ADR-0002：Brand GEO Audit 默认使用诊断报告模式

### 状态

已接受，R1 已实现

### 决策

WorkBuddy MVP 默认使用 `diagnostic` 报告模式，不显示未经校准的正式总分和字母等级

实验性权重和等级仅在显式选择 `experimental_score` 时展示，并同时显示方法学状态、样本数和未知数

### 原因

当前六维权重和等级属于工程参数，尚未完成多行业校准和外部验证。把总分放在默认诊断首页会让读者忽略证据范围和不确定性

### 后果

- v2 评分器继续保留，保证历史结果可复算
- 报告器默认使用 `diagnostic`，只在显式选择 `experimental_score` 时展示总分和等级
- 诊断模式不展示行动建议，只保留观测、证据、缺口与规划交接边界
- `validated_score` 在外部验证前保持不可用
