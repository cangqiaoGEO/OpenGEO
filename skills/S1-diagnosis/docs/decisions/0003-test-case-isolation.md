## ADR-0003：真实品牌测试案例与 Brand GEO Audit 模块隔离

### 状态

已接受

### 决策

任何真实品牌运行都只是可替换、可删除的测试或试点案例，不属于 Skill 的规范内容

真实案例不能成为通用领域对象、Schema 字段、查询类型、指标、权重、阈值或默认建议的唯一来源

### 保存边界

- 真实运行产物保存在 Git 忽略的 `skills/S1-diagnosis/work/` 或独立受控数据集中
- `examples/` 只保存合成或充分脱敏、可公开运行的示例
- `tests/` 只依赖稳定 fixture，不依赖任何真实客户案例
- 方法和架构文档使用明确标记的匿名教学示例

### 删除验收

删除任意一个真实品牌案例后，以下内容必须继续成立：

- Skill 可以被发现和执行
- 所有 Schema 与校验器仍有独立定义依据
- 示例链路仍可运行
- 自动化测试仍通过
- 架构和方法论说明仍然完整
