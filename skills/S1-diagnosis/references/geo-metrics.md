# GEO 品牌诊断指标体系

GEO（Generative Engine Optimization，生成式引擎优化）指优化品牌在生成式 AI 引擎
（ChatGPT、Perplexity、Google Gemini、Microsoft Copilot、DeepSeek、豆包、Kimi、
文心一言等）生成的答案中被提及、被引用、被推荐的概率与质量。

本文件定义品牌 GEO 诊断的全部指标、评分标准、等级划分与建议生成规则。
运行 `scripts/geo_score.py` 可自动计算得分；本文件用于理解指标含义与人工补充判断。

## 1. 诊断维度与权重

| 维度 | 权重 | 含义 |
|------|------|------|
| 可见度 Visibility | 30% | 品牌在 AI 答案中的出现频率与位置 |
| 推荐度 Recommendation | 20% | 品牌被明确推荐而非仅提及的频率 |
| 引用源质量 Citation Quality | 15% | 答案引用来源的权威性、多样性、自有源占比 |
| 信息覆盖度 Coverage | 15% | 品牌核心信息在答案中的完整性与准确性 |
| 情感倾向 Sentiment | 10% | 答案对品牌的态度（正面/中立/负面） |
| 内容基础 Foundation | 10% | 品牌在可被 AI 索引的内容生态中的基础建设 |

综合得分 = Σ(维度得分 × 权重)，满分 100。

## 2. 各维度评分标准（每维度 0-100）

### 2.1 可见度（权重 30%）

对每个测试查询，记录品牌是否出现及其位置：

| 位置 | 单项分 |
|------|--------|
| 首位唯一推荐（答案首推品牌） | 100 |
| 首位并列推荐（与竞品并列第一） | 85 |
| 前 3 提及 | 70 |
| 前 5 提及 | 50 |
| 仅附带/被动提及（列举、对比表中出现） | 30 |
| 未出现 | 0 |

可见度得分 = 0.5 × 出现率 + 0.5 × 各查询位置分均值

- 出现率 = 品牌出现的查询数 / 总测试查询数 × 100

### 2.2 推荐度（权重 20%）

对每个测试查询，记录品牌是否被推荐：

| 推荐状态 | 单项分 |
|----------|--------|
| 明确推荐（"推荐""首选""最佳""值得选择""适合…用户"） | 100 |
| 并列推荐（与其他品牌并列作为候选） | 70 |
| 客观描述、无推荐态度 | 40 |
| 负面/劝阻（"不推荐""口碑差"） | 0 |

推荐度得分 = 各查询推荐分均值。

### 2.3 引用源质量（权重 15%）

对答案中出现的每个引用源，按类型打分：

| 来源类型 | 单项分 |
|----------|--------|
| 品牌官网 / 官方账号 / 官方文档 | 90 |
| 百科 / 知识图谱（Wikipedia、百度百科、维基数据等） | 80 |
| 权威媒体 / 行业报告 / 政府或机构站点 | 75 |
| 第三方评测 / KOL / 深度测评 | 65 |
| 社交媒体 / 论坛 / UGC | 45 |
| 低质聚合站 / 内容农场 | 20 |

- 引用源质量分 = 各引用源得分均值 × min(1, 引用源数量 / 3)（鼓励数量与多样性）
- 若品牌自有源（官网/官方账号）被引用，附加 +10 分，上限 100

### 2.4 信息覆盖度（权重 15%）

检查答案中品牌核心信息的覆盖情况（6 项检查项）：

| 检查项 | 说明 |
|--------|------|
| 品牌基本介绍 | 成立时间、定位、规模、创始人等基础事实 |
| 核心卖点 / 差异化 | 品牌主张、独特价值 |
| 主要产品 / 服务线 | 主力产品或服务 |
| 价格 / 方案信息 | 定价区间、套餐 |
| 用户口碑 / 评价 | 用户反馈、评分 |
| 最新动态 / 新闻 | 近期事件、新品、合作 |

- 覆盖度 = 覆盖项数 / 6 × 100
- 准确性扣分：答案中品牌信息有误（名称、数据、事实错误），每处错误扣 10 分，最低 0 分

### 2.5 情感倾向（权重 10%）

逐句/逐条判断答案对品牌的态度：正面 +1、中立 0、负面 -1。

情感得分 = ((正面占比×1 + 中立占比×0 + 负面占比×(-1)) + 1) / 2 × 100

- 全部正面 = 100；全部中立 = 50；全部负面 = 0

### 2.6 内容基础（权重 10%）

评估品牌在可被 AI 索引的内容生态中的基础建设：

| 检查项 | 满分 |
|--------|------|
| 有百科条目（Wikipedia / 百度百科等）且内容正面 | 25 |
| 官网可被检索，含 FAQ、结构化标记（schema.org）等利于 AI 理解的内容 | 20 |
| 权威第三方内容（媒体/评测/行业报告）≥ 5 篇 | 20 |
| 品牌实体被知识图谱/实体库识别 | 15 |
| 内容生态活跃（近 3-6 个月有新闻/社媒/评测持续更新） | 20 |

内容基础分 = 各项得分之和，上限 100。

## 3. 等级划分

| 等级 | 分数 | 含义 |
|------|------|------|
| S | 80-100 | 优秀，GEO 领先者 |
| A | 60-79 | 良好，有竞争力 |
| B | 40-59 | 中等，需要改进 |
| C | 20-39 | 较弱，明显落后 |
| D | 0-19 | 缺失，几乎不可见 |

## 4. 引擎覆盖矩阵

至少评估 3 个主流引擎，每引擎独立打分并汇总：

- 国际：ChatGPT、Perplexity、Google Gemini、Microsoft Copilot
- 国内：DeepSeek、豆包、Kimi（月之暗面）、文心一言、通义千问

输出引擎对比矩阵：行=引擎，列=可见度/推荐度/引用源/覆盖度/情感 各分及该引擎下品牌位置。

## 5. 建议生成规则

- 对每个得分 < 60 的维度，生成至少 1 条针对性建议；得分 < 40 的维度生成 2 条以上。
- 建议分优先级：P0（1-2 周内执行）、P1（1-2 个月内）、P2（持续进行）。
- 每条建议必须包含：行动项（怎么做）、预期效果（影响哪个指标）、衡量方式（如何验证）。
- 通用建议库（维度 → 常见行动）：

### 可见度低（未出现/位置靠后）
- P0：在官网/官方渠道发布针对高频问题的权威内容（FAQ、对比页、深度指南），覆盖品牌关键词的常见问法。
- P1：在权威第三方平台（百科、行业媒体、评测社区）建立品牌词条与内容，增加被引用的候选源。
- P2：监测品牌关键词在主流 AI 引擎中的出现率，建立月度追踪。

### 推荐度不足（被提及但不被推荐）
- P0：输出差异化价值内容，明确"适合谁、解决什么问题、凭什么选你"的论证型内容。
- P1：争取 KOL / 评测媒体产出体验式内容，形成"第三方背书"语料。
- P2：维护品牌与竞品的对比内容，确保在对比型问题中处于有利位置。

### 引用源质量差（引用少或多为低质源）
- P0：补齐官网 FAQ 与结构化标记（FAQPage、Organization、Product schema），让官方信息成为高可信引用源。
- P1：在百科与权威媒体建立/完善品牌条目，提升引用源权威性。
- P2：定期发布可被引用的原创研究、报告、白皮书。

### 信息覆盖度不足（核心信息缺失/错误）
- P0：发布完整、准确的品牌事实页（简介、产品线、价格、口碑），确保多来源信息一致。
- P1：修正百科与各平台上的过时/错误品牌信息。
- P2：建立品牌信息一致性检查清单，覆盖主要内容平台。

### 情感倾向偏负（答案中负面描述多）
- P0：排查并回应负面内容来源，处理真实客诉与舆情。
- P1：增加正面素材密度（用户案例、成功故事、奖项），稀释负面占比。
- P2：持续监控 AI 答案中的情感倾向变化。

### 内容基础薄弱（无百科/无结构化/内容生态冷清）
- P0：创建或完善百科条目；官网启用 schema.org 结构化标记。
- P1：铺开权威第三方内容（媒体稿、评测、行业榜单）。
- P2：保持内容生态活跃度（月度新闻、社媒、KOL 合作）。
