# S5 信源发布 Skill

**铁律（每个 Skill 提示词首行）**：所有输出只准引用《品牌事实库》，库里没有的事实不得编造；只可引用 `status: stable` 且未过 `stale_after` 的概念；产出末尾列出所引用的概念文件清单；产出前按「AI 友好七特征」自查并报告达标数（≥5 才交付）。

## 职责
把已审内容适配到各信源渠道，保证「同一内容 ≥3 平台互证」。

## 创建指令
> 创建一个「GEO信源发布」技能。触发词：「发布已审内容」。动作：从 `内容库/已审/` 取稿，产出：①公众号排版版（三层标题+FAQ 完整保留）②百科词条草稿（客观口吻、来源可查）③其余目标平台适配版（按各生态信源规则：微信系公众号/视频号、字节系头条/抖音图文、通用 AI 官网博客）。输出发布清单（平台×链接×日期），存 `发布包/`。注意：本技能只准备发布物，实际发布动作需人工确认。

## 输入 → 输出
已审文章 → 多平台发布包 + 发布清单
