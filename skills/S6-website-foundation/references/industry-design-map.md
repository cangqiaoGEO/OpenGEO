# 行业 × 设计语言映射表

官网生成的核心差异化来源。**每次生成前必读本表**，按行业选择设计语言；禁止脱离行业直接套模板。

> 使用方式：查到行业后，将对应「设计 token」写入 HTML 的 `:root` CSS 自定义属性；字体、版式、组件、动效按列执行。所有配色在浅色/深色背景下的可读性必须自检（深色底配浅字，浅色底配深字）。

---

## 1. AI / 科技 / 互联网

| 维度 | 规范 |
|---|---|
| 气质 | 冷静、未来感、理性、极简科技 |
| 配色 | 主色 `#0A0E1A`（深空黑）或 `#0B1B3A`（深蓝）；辅色 `#3B82F6→#8B5CF6` 渐变（电光蓝紫）；强调金 `#C9A55C`；浅色方案：`#F7F9FC` 底 + `#0B1B3A` 文 + `#3B82F6` 点缀 |
| 字体 | 标题：Inter/「PingFang SC」字重 700-800 加宽字距；正文：同族 400。数字用等宽感字体 |
| 版式 | 全宽 Hero + 大号无衬线标题；卡片网格；几何网格背景（细线 1px，透明度 ≤6%） |
| 组件 | 玻璃拟态卡片（backdrop-filter: blur + rgba 白 8-12%）、光晕按钮、数据大屏式数字、代码/终端风格角标 |
| 动效 | 渐入 + 轻微上移；hero 光晕呼吸；卡片 hover 微升 4px 加描边高亮 |
| 意象 | 星云/数据流/神经网络线条、等距网格、发光点阵 |

|---|---|

## 通用高端法则（行业不在表内时）

1. **先定气质**：名称/行业 → 用 4 个形容词描述（如"冷静、理性、先锋、可信"），再对应色板与字体。
2. **色板原则**：主色 1 + 辅色 1 + 中性色 2-3；全部色值写入 CSS 变量；对比度满足 WCAG AA（正文 ≥4.5:1）。
3. **字体原则**：标题/正文 2 族以内；标题靠字重与字距做层级，不用花哨字体；一律系统字体栈（`"PingFang SC","Noto Sans SC","Microsoft YaHei",sans-serif` 或衬线 `Georgia,"Songti SC",serif`）。
4. **奢侈感三件套**：大留白、细线框（1px 低透明度描边）、克制金色/金属色点缀（占比 ≤5%）。
5. **避免廉价信号**：不用刺眼纯色渐变（除非科技行业）、不用大圆角卡通风、不用 emoji 当图标、不用阴影叠阴影。
