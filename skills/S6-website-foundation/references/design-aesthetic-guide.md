# 高端审美设计原则

目标是让官网看起来"贵"：不是堆砌元素，而是**克制、秩序、质感**。以下原则在生成时逐条落地。

---

## 一、配色法则

1. **60-30-10**：中性色打底 60%，主色 30%，强调色 10%。主色 ≤3 个（含强调）。
2. **深色 = 奢华**：深色 Hero（墨黑/深蓝/深绿）配合大留白，是最高效的"高级感"来源；但正文区回到浅色，保证可读与信任。
3. **金/金属色克制使用**：仅用于强调线、小图标、徽章、按钮 hover，占比 ≤5%，避免暴发户感。
4. **对比度**：正文对比度 ≥4.5:1（WCAG AA）；装饰性文字不受限。
5. **禁用**：饱和度过高的纯色渐变（红紫蓝大杂烩）、荧光色、大面积高饱和色。

## 二、字体排印

1. **两族以内**：标题族 + 正文族。科技/金融可加等宽数字族。
2. **层级靠字重与字距**：H1（700-800 / letter-spacing 0.02em / 2.5rem+）→ H2（600 / 1.75-2rem）→ 正文（400 / 1rem-1.125rem / line-height 1.7）。
3. **数字用 tabular-nums**（统计、价格对齐）。
4. **行宽**：正文段落 max-width 60-70ch，避免整屏通栏文字。
5. **系统字体栈**：`font-family: -apple-system, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;`（衬线方案：`Georgia, "Songti SC", "SimSun", serif;`）。禁止外链字体（单文件原则）。

## 三、留白与栅格

1. **留白是奢侈品**：区块间距 ≥96px（桌面），卡片内边距 ≥32px；宁可内容少，不可挤。
2. **栅格对齐**：内容容器 max-width 1200px，12 列网格心理；卡片间距统一（24px/32px 两档）。
3. **细线分隔**：区块间用 1px 低透明度描边（如 `#00000010`）而非粗阴影。
4. **区块节奏**：交替"满图/白底/深底"，避免连续同质区块。

## 四、动效（克制是高级）

1. **scroll-reveal**：IntersectionObserver 实现，元素渐入 + 上移 16-24px，duration 500-700ms，stagger ≤120ms。禁用手写复杂的滚动库。
2. **hover 反馈**：卡片抬升 ≤4px + 描边高亮；按钮填充色过渡；链接下划线从左展开。
3. **数字滚动**：count-up 动画用于统计区（1000ms ease-out）。
4. **禁用**：弹跳、旋转入场、闪烁、跑马灯、自动轮播（除非用户要求）。

## 五、图片策略（无真实图片时的占位视觉）

无真实图片时**禁止**使用"图片占位符"灰色框 + 文字。改为生成高级占位视觉：

1. **渐变几何**：`linear-gradient(135deg, 主色, 主色变体)` + 叠加细网格/圆环/斜线（用 repeating-linear-gradient 或 SVG）。
2. **行业意象几何**：科技=点阵/线条网格；金融=上升曲线/圆形印章；文化=宣纸纹理/水墨圆；家居=木纹色块/窗格。
3. **首屏 Hero**：深色渐变 + 光晕（radial-gradient）+ 细网格 + 大号标题，本身就是完整视觉。
4. **人物/产品图**：用几何剪影（SVG circle/圆角矩形 + 渐变）代替真实图，标注注释供替换。
5. **留白即画面**：很多高级页面不需要"图"，用排版本身构成视觉。

## 六、组件质感细节

| 元素 | 高端做法 | 廉价做法 |
|---|---|---|
| 卡片 | 白底 + 1px `#00000012` 描边 + 圆角 12-16px + 阴影极浅 | 彩色投影、粗描边、夸张圆角 |
| 按钮 | 主按钮实心 + 微光晕；次按钮描边式 | 渐变彩虹、发光过度 |
| 图标 | 线性图标（1.5px stroke）或几何符号 | emoji、贴图式图标 |
| 徽章 | 细描边 + 小字距 + 半透明底 | 高饱和实心圆角徽章 |
| 数字 | 大号 + tabular + 单位小字 + 顶部分隔线 | 彩色加粗圆角标签 |
| 列表 | 编号 01/02/03 + 细分隔线 | 圆点 + 缩进 |

## 七、响应式要点

- 断点：≥1024px 桌面 / 768px 平板 / ≤480px 移动。
- 移动端：汉堡菜单（原生 JS 切换）；卡片单列；大标题用 `clamp()` 缩放（如 `clamp(2rem, 5vw, 3.5rem)`）。
- 深色区块在移动端保持深色，浅色正文区保持浅色，不做模式切换。

## 八、HTML/CSS 实现规范

- 设计 token 全部放 `:root` 的 CSS 变量（`--c-primary`、`--c-gold`、`--font-head`、`--space-section` 等），一页换肤只改变量。
- 组件类名语义化（`.hero`、`.stat`、`.faq-item`），不依赖 UI 框架。
- 原生 JS 控制在 60 行内（reveal + countup + 移动菜单 + FAQ 折叠），放 `</body>` 前。
- 动效优先 CSS（transition/transform），JS 只做触发。
