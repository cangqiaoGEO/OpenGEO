## 一周学习路径

1. **第 1–2 天**：读 README + GOVERNANCE；本地跑一次 `okf_lint` 和 `run_audit.py`；
2. **第 3–5 天**：按自己那一层动手（详见[全员学习手册](https://github.com/cangqiaoGEO/OpenGEO/blob/main/docs/team-handbook.md)第三部分）；
3. **第 5 天**：全员桌面推演「一个客户从 0 到复测」；
4. **验收**：10 题答对 8 题。
